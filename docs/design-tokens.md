# Design tokens

## Sticker colors

Each sticker has a hex color used for its badge text and border ring.
The badge background is the same hex with 15 % opacity (`color + "26"`).

| Slug             | Name           | Hex       | Tailwind analogue |
|------------------|----------------|-----------|-------------------|
| `check-in`       | Check-In       | `#2563EB` | blue-600          |
| `prayer-request` | Prayer Request | `#7C3AED` | violet-600        |
| `praise-report`  | Praise Report  | `#D97706` | amber-600         |
| `offering-help`  | Offering Help  | `#059669` | emerald-600       |
| `need-help`      | Need Help      | `#DC2626` | red-600           |
| `event-meetup`   | Event / Meetup | `#DB2777` | pink-600          |
